# 待办日历应用 - SPEC.md

## 1. 项目概述

- **项目名称**: TodoApp
- **类型**: 桌面日历待办应用
- **核心功能**: 带日历视图的待办事项管理，支持按天/按时间查看和设置
- **目标用户**: 需要日历+任务管理一体化的用户

## 2. UI/UX 规范

### 窗口特性

- **边框**: 可拖动调节大小（上下左右四条边 + 四个角）
- **拖动条**: 顶部标题栏可拖动窗口
- **最小尺寸**: 600x500
- **默认尺寸**: 800x600

### 布局结构

```
┌──────────────────────────────────────┐
│ [拖动条] 待办日历              [×]   │
├─────────────────┬────────────────────┤
│                 │                    │
│   日历月视图     │    当日待办详情      │
│   (可点击日期)   │    (时间线列表)      │
│                 │                    │
│                 │                    │
│                 │                    │
└─────────────────┴────────────────────┘
```

### 视觉设计

- **配色**:
  - 背景: rgba(25, 25, 45, 0.98)
  - 卡片: rgba(40, 40, 65, 0.95)
  - 文字: #ffffff
  - 次要文字: #8888aa
  - 强调色: #00ff88 (亮绿)
  - 周末色: #ff8866 (橙红)
  - 今日本地: #00ff88 边框

- **字体**: system-ui, 14px 正文

### 组件

1. **DragBar** - 标题栏拖动
2. **CalendarGrid** - 月历网格
3. **DayCell** - 单个日期格子（含今日指示、有无待办指示）
4. **DayDetail** - 当日待办详情面板
5. **TimeSlot** - 时间槽位（00:00-23:59，可设置待办）
6. **TodoItem** - 待办事项（时间 + 内容 + 删除）

## 3. 功能规范

### 日历功能

- 显示当前月份，左箭头/右箭头切换月份
- 星期标题栏（周一至周日）
- 日期格子显示日期号
- 今日高亮（绿色边框）
- 有待办事项的日期显示圆点标记
- 点击日期选中，显示当日详情

### 待办功能

- 每日待办列表，按时间排序
- 添加待办：输入时间 + 内容
- 点击复选框完成（画横线）
- 点击删除按钮删除
- 完成待办显示横线

### 数据存储

```typescript
interface Todo {
  id: string;
  date: string;       // "YYYY-MM-DD"
  time: string;       // "HH:mm"
  text: string;
  completed: boolean;
}
```

localStorage 持久化
