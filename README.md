# TodoApp - 桌面待办日历

一款简洁美观的桌面待办应用，支持日历视图和日程管理。

## 功能特点

### 📅 周视图日历
- 7天周视图，直观展示一周日程
- 拖拽调节列宽，适应不同屏幕
- 每个日期格子可独立调节高度
- 拖拽待办事项移动到其他日期

### ✅ 待办管理
- 快速添加待办事项（时间 + 内容）
- 支持重复提醒：每天、每周、每月、每年
- 桌面通知提醒功能
- 勾选完成自动跳转下次日期

### 🎨 界面定制
- 背景透明度调节
- 卡片透明度调节
- 主题色自由切换

### 🖥 桌面集成
- 窗口可自由拖动调整大小
- 数据本地存储（localStorage）
- 无需联网，即开即用

## 技术栈

- **前端**: React + TypeScript + Vite
- **桌面**: Tauri (Rust)
- **样式**: CSS Variables
